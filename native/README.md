# 유튜브 추출기 — 기기에서 직접 실행

Windows와 Android용 초기 버전입니다. Render나 다른 추출 서버에 접속하지 않습니다.
사용하는 기기의 인터넷 연결과 저장 공간으로 작업합니다. 앱 사용에는 AI API나 토큰이 필요하지 않습니다.
유튜브 측 변경·접근 제한에 따라 추출이 실패할 수 있습니다. 설치형도 성공을 보장하지는 않습니다.

## Windows 10/11 (64비트)

1. `YouTubeExtractor-Windows.zip`을 압축 해제합니다.
2. 폴더 안의 `YouTubeExtractor.exe`를 실행합니다. `_internal` 폴더도 함께 있어야 합니다.
3. 링크와 종류를 선택하고 추출합니다. 기본값은 시간 없는 TXT 자막입니다.
4. `폴더 열기`에서 파일을 확인합니다. 기본 저장 위치는 사용자 Downloads의 YouTube Extractor 폴더입니다.

Python, Node, FFmpeg를 따로 설치할 필요가 없습니다. 유료 코드 서명이 없는 초기 배포본입니다.
프로그램을 종료하면 진행 중 작업도 취소됩니다. 오류 진단 파일은 결과 폴더의 `진단.log`입니다.

## Android 8 이상 (64비트 ARM / x86_64)

1. `YouTubeExtractor-Android.apk`를 휴대폰에서 열어 설치합니다.
2. Android가 요청하면 해당 브라우저/파일 앱에 이 APK 설치 권한을 허용합니다.
3. 링크를 붙여넣거나 YouTube 공유 메뉴에서 유튜브 추출기를 선택합니다.
4. 추출 후 `파일에 저장`을 눌러 저장 위치를 선택합니다.

처리 중 앱을 화면에 열어 두세요. 화면이 꺼지거나 OS가 앱을 종료하면 작업이 중단될 수 있습니다.
Android 파일 전체 접근 권한은 요구하지 않습니다. 엔진 업데이트 버튼은 공식 yt-dlp 배포처를 사용합니다.
초기 APK는 개발용 서명입니다. 다른 서명의 후속 APK 설치에는 기존 앱 제거가 필요할 수 있으므로 결과를 먼저 저장하세요.

## 자막

영상이 제공하는 일반/자동 자막을 사용합니다. 음성 인식으로 새 자막을 만들지 않습니다.
TXT는 타임코드를 제거하고 내용을 이어 씁니다. 원본 `이름:` 및 `>>` 화자 표시는 문단으로 보존합니다.
원본에 없는 화자 이름을 추측하거나 목소리로 구분하지 않습니다.
영상·음성·자막에 15분 제한을 적용하지 않습니다. 개별 다운로드 파일은 2GB로 제한합니다.

## 배포 및 테스트 범위

GitHub Actions의 공개 저장소 표준 실행기에서 설치 파일을 빌드합니다. 운영 서버가 아닙니다.
Windows/Android 소스와 빌드 결과를 함께 제공합니다. Android 실제 휴대폰 실행은 별도 기기 확인이 필요합니다.
아이폰은 이번 버전의 지원 대상이 아닙니다.

본인 소유 또는 저장 허가를 받은 콘텐츠에 사용하세요.
